## 3.（選做）鯉魚拆成零件 — 參考影片的做法

參考影片的魚不會「一塊一塊」，是因為魚被**拆成身體、胸鰭、尾巴幾個零件**，各自擺動，尾巴像絲帶一樣慢半拍跟著。
我們現在是整張圖一起彎，所以長在身上的鰭會被擠到。

做法：拿**之前生好的鯉魚圖**，請 ChatGPT 改圖（不是重畫），每隻魚做兩張：

**3-1. 只留身體** → 存成 `koi-platinum-body.png`（另外兩隻同樣做）

> Edit the attached image. Remove ALL fins and the tail, keeping ONLY the body (head to the base of the tail). Keep the body exactly the same — same position, same size, same colors, same lighting, same canvas size. Transparent background PNG. Do not redraw or move anything.

**3-2. 只留鰭和尾巴** → 存成 `koi-platinum-fins.png`

> Edit the attached image. Remove the body, keeping ONLY the fins and the tail, exactly where they are now — same position, same size, same colors, same canvas size. Fill the gap where the fins met the body softly. Transparent background PNG. Do not redraw or move anything.

ChatGPT 改圖時位置可能會跑掉一點點，沒關係，我會用程式對齊。
